OBS 用の**ローカル・リアルタイム日本語→中国語字幕**です。マイクの音だけを拾い、ゲーム音には触れず、音声を外部へ送信しません。すべてオフラインで動きます。

対象は日本語の**雑談**と**ゲーム実況**。**歌枠・歌詞は対象外**です。

> **0.4.0 のポイント**：UI を全面的に日本語化し、辞書を **292 フレーズ / 155 用語**に拡充しました。
> 0.3.x から移行する場合は、旧フォルダの `config.toml` と `glossary\` を新しいフォルダへコピーすれば
> 設定と追加した辞書を引き継げます。

## 1. 起動

1. 任意のフォルダに解凍（パスに日本語や中国語を含めないほうが安定します）
2. `LiveSub-0.4.0\LiveSub.exe` をダブルクリック
3. 初回に「不明な発行元」と出たら **詳細情報 → 実行**（コード署名をしていないため）
4. 黒いウィンドウが開きます。**閉じると字幕が止まります**

ウィンドウに表示されるアドレス：

```
字幕ページ ：http://127.0.0.1:8765/overlay
設定ページ ：http://127.0.0.1:8765/admin
デバッグ　 ：http://127.0.0.1:8765/overlay?debug=1
```

---

## 2. OBS への追加（初回のみ・約 1 分）

1. OBS の **ソース** パネル → **`+`**
2. **ブラウザ** を選択
3. 名前は任意（例：`字幕`）→ OK
4. プロパティに次を入力：

| 項目 | 値 |
|---|---|
| URL | `http://127.0.0.1:8765/overlay` |
| 幅 | `1920` |
| 高さ | `1080` |

5. **「ソースが非表示のときにシャットダウン」はオフ**（オンにするとシーン切替のたびに再読み込みされ、字幕がちらつきます）
6. 背景は最初から透明です。クロマキーや色キーの設定は不要

> 配信せずに見た目を確認したいとき：ブラウザで `http://127.0.0.1:8765/overlay?preview=1`

---

## 3. 文字・色・サイズ・背景の調整

ブラウザで **`http://127.0.0.1:8765/admin`** を開きます。

左が **1920×1080 のリアルタイムプレビュー**、右が設定です。変更するとプレビューがすぐ変わり、
「保存して適用」で **OBS の字幕にも即時反映**されます（プログラムの再起動も OBS の再読み込みも不要）。

変更できる項目：

- **フォント**：インストール済みのフォント名（例：`游ゴシック`）。カンマ区切りで複数指定可
- **文字サイズ**：中国語・日本語を別々に
- **色**：中国語・日本語を別々に
- **縁取り**：オン／オフ＋色＋太さ
- **背景**：半透明の長方形（色＋透明度）。黒＋透明度で黒帯
- **位置**：下／上、端からの距離（%）
- **行数**：同時に表示する行数
- **二言語**：日本語の原文を表示するか

## 4. 辞書の追加（誤訳を見つけたらここ）

同じ設定ページの **「辞書」** タブに 2 つの表があります。

### 定型フレーズ（文全体）

**その文を丸ごと言ったときだけ**有効になります。挨拶や配信の決まり文句向け：

| 日本語 | 中国語 |
|---|---|
| こんばんは | 晚上好 |
| おつかれさまでした | 辛苦了 |
| なるほど | 原来如此 |

### 用語（語単位）

モードを間違えると逆効果になります：

| モード | 動作 | 向いているもの |
|---|---|---|
| `pre` | 翻訳前に日本語の語を中国語へ置換してからモデルへ渡す | カタカナの固有名詞・ゲーム名・食べ物名（モデルは注入した中国語をそのまま残します） |
| `post` | 通常どおり翻訳し、訳文の「誤訳パターン」を置換 | 文の構造は合っていて、その語だけ違う場合（例：`配信` → 「发送」） |

`post` の誤訳パターンは `|` 区切りで複数指定できます（例：`发送|发货|传送`）。

**「辞書を保存して即時反映」** を押せば、再起動なしで反映されます。
下の **試し翻訳** に 1 文を入れると、その場で結果を確認できます。

> 辞書はプログラムのフォルダの `glossary\` に書き出されます（UTF-8・Tab 区切りのテキスト）。
> 手で編集することもできます。内蔵版に戻したいときは、このフォルダを削除して再起動してください。

---

## 5. 設定ファイルで変更する場合

すべての設定はプログラムのフォルダの `config.toml` にもあります（日本語コメント付き）。
ファイルを直接編集した場合は再起動が必要です。
辞書は `glossary\phrases.tsv` と `glossary\terms.tsv` です。

## 0.4.0 の変更点（0.3.1 から）

- **UI をすべて日本語化**：起動時のコンソール、設定ページ、字幕ページのデバッグ表示、
  `config.toml` のコメント、ポータブル版の `使い方.txt`、このリリースノート
- **辞書を拡充**：定型フレーズ **292** 件、用語 **155** 件。
  挨拶・配信の開始／終了・視聴者とのやり取り・ゲーム実況の定番表現・配信トラブル・告知まで収録
- **README を日本語のユーザー向け説明に全面改稿**。開発状況・品質データは
  開発者向けドキュメント（中国語）に分離
- 0.3.1 からの機能（そのまま利用できます）：
  - グラフィカル設定ページ `/admin`（スタイルのリアルタイムプレビュー、辞書の追加・削除・即時反映）
  - 翻訳前の句読点補完（認識結果には句読点がないため、文末に補います。0ms）
  - デコードの暴走対策と訳文クリーニング（繰り返し崩れの打ち切り、孤立した引用符・句読点の整理）

## 既知の問題

1. **未署名**のため、初回起動時に「不明な発行元」と表示されます（正常です）
2. パッケージが大きい（解凍後 約 600MB）。大半はモデルです
3. 二重起動するとポート使用中で終了します（メッセージは出ますが、単一インスタンス化は未実装）
4. OBS のシーン連動・ドロップ監視・ワンキー非表示は未実装です
5. Windows x64 のみ対応
