# LiveSub 0.5.2 — 开箱即用（自动通道 + 自动保存）

发布日期：2026-10-23

## 这次解决什么

0.5.1 的「输入チャンネル」是手动开关，默认仍然是 `0`（输入1）。两名测试者都使用 2ch
音频接口，但都没有意识到要改通道或按保存，结果仍然是「电平在动、字幕不出」；开发机是
1ch USB 麦克风，无法复现。

还有一个更直接的共同原因：0.5.1 的音频页把「システム既定」选项的 `value=""` 用
`+value` 转成了 `0`，保存时写成了 `device_index = 0`。在 Windows/PortAudio 上 index 0
通常是 `Microsoft Sound Mapper`，不是真正的默认麦克风。只要用户点过一次音频页的保存，
之后就会一直抓着 Sound Mapper；截图里的「動作中のデバイス：Microsoft サウンド マッパー」
正是这个状态。开发机没有保存过音频设置，所以默认 USB 麦克风一直正常。

0.5.2 修复了这个空值转换，并在读取旧配置时把 `device="" / device_index>=0` 迁移回
`-1`（系统默认）；同一次错误保存如果还写了 `channel=0`，也一并迁移到 `-2`（自动）。
显式选过输入2（`channel=1`）或混音（`-1`）的配置不受影响。即使配置里明确保存了
`Microsoft Sound Mapper` / `Primary Sound Capture`，读取时也会回到实际默认设备
（这两个是 Windows 的转送端点，不是麦克风）。
同时把默认值改成 **自动通道**，并把设置页的所有修改改成 **自动保存**。

## 1. 输入通道自动判定

- 新配置 / 没有写过 `channel` 的旧配置默认 `channel = -2`（自动）。
- 判定前：把当前 RMS 最大的通道直接送给 VAD/ASR。这样即使麦克风在输入2，也不会先被
  混成半音量或被输入1的串音挡住。
- 累计约 **600ms** 的 VAD 发话后：比较各通道在发话期间的平均 RMS，锁定最大的那一路。
- 锁定后：设置页显示「自動判定: ch2 を使用中」。用户仍可从下拉框改为
  1 / 2 / すべてミックス；手动选择会写入 `config.toml`，下次启动保持不变。
- 1ch 麦克风：自动退化为原来的单通道，界面不显示通道选择。
- 不确定时（声音太小、都是噪声）：不锁定，继续听；不会随便选一个通道。

限制：如果输入1是持续很响的游戏音、输入2才是麦克风，单靠能量无法区分；这种情况请手动选 2。
自动判定是「少配一步」的兜底，不是声源分离。

## 2. 设置页自动保存

| 页面 | 行为 |
|---|---|
| スタイル | 输入后 450ms 防抖保存，预览实时更新，OBS 立即收到新配置 |
| 音声 | 设备/通道改变后约 80ms 保存；增益/阈值停止拖动 650ms 后保存 |
| 辞書 | 输入/删除/切换模式后 900ms 防抖保存，不重绘表格（保护光标） |
| 記録 | 开关本来就是即时保存 |

保留「今すぐ保存」按钮作为手动兜底；音频页在设备选择旁也放了一个，避免用户找不到。
自动保存失败时状态栏会显示错误，不会静默丢失。

## 3. 兼容性

- 旧配置里显式写了 `channel = 1`（输入2）或 `-1`（混音）的，继续按手动值使用；没有写
  `channel` 的旧配置会得到新的自动默认。`channel = 0` 只有在同时命中 `device="" /
  device_index>=0` 这个旧保存 bug 时才迁移到自动，其他情况保持手动。
- `config.toml` 仍是 UTF-8、保留注释；只改 `[audio]` / `[vad]` / `[overlay]` 的相关行。
- 不需要重装模型；覆盖 exe / 整个绿色版目录即可。

## 4. 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

结果：**89 tests OK**。

新增回归：

- `test_auto_selects_the_channel_with_speech`：只有 ch2 有声时自动选 ch2。
- `test_auto_does_not_lock_without_speech`：静音时不锁定。
- `test_auto_can_be_overridden_manually`：锁定后手动改回 ch1。
- `test_auto_on_mono_device_is_mono`：1ch 设备退化为单通道。
- `test_empty_device_with_stale_index_uses_system_default`：旧版 `device="" / index=0`
  迁移到默认设备；同一次保存的 `channel=0` 迁移到自动，显式 `channel=1` 保留；
  显式 `Microsoft Sound Mapper` 也会回到默认设备。
- 设置页字符串检查包含「自動（推奨）」「save-audio-top」「自動保存」。

## 5. 给测试者的最短说明

> 0.5.2 では、2ch インターフェースの入力チャンネルは「自動（推奨）」が既定です。
> 最初に日本語で一度話すと、声が入っている側を自動で選びます。
> 設定ページの変更は自動保存されるので、「保存して適用」を押す必要はありません。
> うまくいかないときだけ「音声」タブで 1 / 2 / すべてミックスを手動で選んでください。
