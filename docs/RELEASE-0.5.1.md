# LiveSub 0.5.1 — 「字幕が出ない」を自分で切り分けられる版

0.5.0 を入れた方から **「レベルメーターは動くのに字幕がまったく出ない」** という報告を受け、
原因をリモートで特定できるようにした診断版です。認識モデル・翻訳モデル・遅延は 0.5.0 と同じ。

## 追加したもの

### 1. 設定ページ「診断」タブ

音声 → 声の検出 → 切句 → 認識 → 字幕 → OBS 接続 の 6 段を ✓／!／✕ で表示し、
一番下に「判定」を 1 行で出します。

- **直近6秒で認識テスト**：いま届いている音声をそのまま認識し直します。
  ここで文字が出れば認識は正常（原因は OBS 側）、出なければマイク側です。
  テストした音声は `logs/diag-recent-*.wav` に保存されます。
- **サポート用ファイルを保存**：設定・直近10秒の音声・ログ末尾・診断 JSON を 1 つの zip にします。
  自動送信はしません。聞かれたときだけ送ってください。

### 2. 入力チャンネルの選択（2ch オーディオインターフェース）

MOTU / UR22 / AG03 などでマイクを **入力2** に挿していると、これまでは 1ch 目だけを見ていたため
「レベルは動くのに声が入っていない」状態になっていました。これが今回の本命の修正です。

「音声」タブ → **入力チャンネル** で `1` / `2` / `すべてミックス` を選べます。
既定は `1`（従来と同じ）なので、既存の環境の音声経路は変わりません。
メーターの下に **ch 別レベル** が出るので、声がどちらに入っているか一目で分かります。

### 3. 空の認識結果が見えるように

これまで ASR が空文字を返しても、どこにも記録が残りませんでした（画面にもログにも出ない）。
`/api/diag` と診断タブに `asr_empty`（空だった回数）を出します。

## 使い方

1. `LiveSub.exe` を起動（設定ページが自動で開きます）
2. 「診断」タブ → 状態を確認
3. 文字が出ないときは「音声」タブで **入力チャンネル** を 2 か すべてミックス に
4. 解決しないときは「サポート用ファイルを保存」

## API（開発者向け）

| エンドポイント | 内容 |
|---|---|
| `GET /api/diag` | 段ごとのカウンタ・接続数・チャンネル別レベル・判定 |
| `POST /api/diag/recent` | 直近 N 秒を認識し直す（`{"seconds": 6}`） |
| `GET /api/diag/bundle` | サポート用 zip |

## 検証

- 単体テスト 84 件（チャンネル選択・空認識の可視化・判定ロジックを含む）
- 実機（1ch USB マイク）で `channel` のホットスイッチ、`/api/diag`、zip 生成を確認
- 既存の 0.4.0 / 0.5.0 の `config.toml` はそのまま使えます（`channel` は既定 0）

## 既知の制限

- 3ch 以上のインターフェースは「すべてミックス」でしか使えません（ch 指定は 1〜2 が対象）。
- 「診断」の判定は信号経路の順番で出すだけで、OBS のシーン設定までは見ません。
