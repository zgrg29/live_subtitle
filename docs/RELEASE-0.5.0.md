OBS 用の**ローカル・リアルタイム日本語→中国語字幕**です。マイクの音だけを拾い、ゲーム音には触れず、音声を外部へ送信しません。すべてオフラインで動きます。

対象は日本語の**雑談**と**ゲーム実況**。**歌枠・歌詞は対象外**です。

> **0.5.0 のポイント**：配信者からの 5 つのフィードバックを反映しました。
> 字幕の自動消去、マイク選択、音量メーター、起動時の設定ページ自動表示、任意の記録（既定オフ）。
> あわせて辞書ページを折りたたみ式にし、追加ボタンを表の上に移しました。

## 1. 起動

1. 任意のフォルダに解凍（パスに日本語や中国語を含めないほうが安定します）
2. `LiveSub-0.5.0\LiveSub.exe` をダブルクリック
3. 初回に「不明な発行元」と出たら **詳細情報 → 実行**（コード署名をしていないため）
4. 黒いウィンドウが開きます。**閉じると字幕が止まります**
5. 起動後に **設定ページがブラウザで自動的に開きます**
   （開かない場合は <http://127.0.0.1:8765/admin>。`--no-browser` を付けると自動表示を止められます）

ウィンドウに表示されるアドレス：

```
字幕ページ ：http://127.0.0.1:8765/overlay
設定ページ ：http://127.0.0.1:8765/admin
デバッグ　 ：http://127.0.0.1:8765/overlay?debug=1
```

---

## 2. OBS への追加（初回のみ・約 1 分）

1. OBS の **ソース** パネル → **`+`**
2. **ブラウザ** を選択
3. 名前は任意（例：`字幕`）→ OK
4. プロパティに次を入力：

| 項目 | 値 |
|---|---|
| URL | `http://127.0.0.1:8765/overlay` |
| 幅 | `1920` |
| 高さ | `1080` |

5. **「ソースが非表示のときにシャットダウン」はオフ**（オンにするとシーン切替のたびに再読み込みされ、字幕がちらつきます）
6. 背景は最初から透明です。クロマキーや色キーの設定は不要

> 配信せずに見た目を確認したいとき：ブラウザで `http://127.0.0.1:8765/overlay?preview=1`

---

## 3. 設定ページ（スタイル / 音声 / 辞書 / 記録）

ブラウザで **`http://127.0.0.1:8765/admin`** を開きます。
左が **1920×1080 のリアルタイムプレビュー**、右が設定です。変更するとプレビューがすぐ変わり、
「保存して適用」で **OBS の字幕にも即時反映**されます（再起動も OBS の再読み込みも不要）。

### スタイル

- **フォント**：インストール済みのフォント名（カンマ区切りで複数指定可）
- **文字サイズ・色**：中国語と日本語を別々に
- **縁取り・背景**：オン／オフ＋色＋太さ／透明度
- **位置・行数・二言語表示**
- **字幕を消すまでの時間**：無音のときに最後の字幕を残す秒数（既定 5 秒、0 で消さない）。

### 音声

- **入力デバイス**：マイクを選ぶ。保存すると**再起動なしで切り替わります**
  （同名のマイクが複数あっても選び分けられます）
- **入力ゲイン**：小さい声のときに上げる（0.5〜8.0 倍）
- **認識しきい値**：この線を超えた音を「声」とみなします。小さい声を拾うなら下げます
- **入力レベルメーター**：OBS のようなリアルタイム表示。声を出したとき、青い線を超えるように調整してください

### 辞書

「定型フレーズ」と「用語」の 2 つの表は、**見出しをクリックすると開きます**（既定は閉じています）。
見出しの右に件数が出ます。展開すると **「＋ 追加」が表の上**にあります。

### 記録（既定オフ）

認識・翻訳の改善用に、マイク音声と字幕をこの PC に保存できます。
**外部には送信しません。** 通常はオフのままで構いません。
オンにすると `recordings\年月日-時刻\` に次のファイルが作られます：

| ファイル | 内容 |
|---|---|
| `audio-000.wav` | マイク音声（16kHz / 16-bit / モノラル）。60 分を超えると分割 |
| `lines.jsonl` | 1 行 = 1 字幕。日本語・中国語・時刻・音声内の開始/終了秒 |
| `meta.json` | バージョン、使用モデル、マイク、設定のスナップショット |

不要になったらフォルダごと削除してください。
録音には通話や来客など他の人の声も入り得るので、共有する前に本人の同意を確認してください。

## 4. 0.5.0 の変更点（0.4.0 から）

- **字幕の自動消去**：最後の字幕から 5 秒（既定）無音が続いたらフェードアウト。
  長い文は読み終わるように自動で少し延長（最大 15 秒）。設定ページのスライダーで 0〜30 秒に変更可
- **マイク選択**：設定ページの「音声」タブから選択。保存後すぐ切り替わり、
  同名デバイスも `device_index` で区別。新しいマイクが開けないときは旧デバイスへ自動で戻ります
- **音量メーターとしきい値調整**：入力ゲイン、認識しきい値（dBFS）、リアルタイムレベル表示。
  小さい声が拾われないときは、ゲインを上げるか、しきい値を下げます
- **起動時に設定ページを自動表示**：`/api/health` が応答してからブラウザを開きます
  （`--no-browser` で無効、`[ui] open_admin = false` でも無効）
- **任意の記録（既定オフ）**：音声 + 認識/翻訳結果をローカル保存。設定ページの「記録」タブで即時オン／オフ
- **辞書 UI の改善**：2 つの表を既定で折りたたみ。展開時の「＋ 追加」を表の上に移動
- 0.4.0 の機能（そのまま利用できます）：
  - UI の日本語化、定型フレーズ 292 件 / 用語 155 件
  - グラフィカル設定ページ（スタイルのリアルタイムプレビュー、辞書の追加・削除・即時反映）
  - 翻訳前の句読点補完、訳文クリーニング、断句の保留・統合

## 翻訳品質（正直な話）

| 評価セット | 0.3.x | 0.4.0 / 0.5.0 |
|---|---|---|
| 書き言葉 60 文 | 0.354 | **0.610** |
| 句読点なし（＝認識出力に近い） | 0.273 | **0.504** |
| VTuber 口語 37 文 | 0.180 | **0.259** |

- ✅ 挨拶・頻出の口語・固有名詞・配信プラットフォーム用語・ゲーム用語は読めます
- ⚠️ 配信者が長く話す文の語気・論理接続は、**半分ほど推測**になります
- ❌ 歌詞・方言・複数人の同時発話は対象外です

## 既知の問題

1. **未署名**のため、初回起動時に「不明な発行元」と表示されます（正常です）
2. パッケージが大きい（解凍後 約 600MB）。大半はモデルです
3. 二重起動するとポート使用中で終了します（メッセージは出ますが、単一インスタンス化は未実装）
4. OBS のシーン連動・ドロップ監視・ワンキー非表示は未実装です
5. Windows x64 のみ対応
6. 設定ページの自動表示は、ブラウザが既に開いていると新しいタブが背景になることがあります
