给 OBS 用的**本地实时日语→中文字幕**。只采集你的麦克风，不碰游戏声音，不上传任何音频，全程离线。

适用场景：日本 VTuber 风格的**雑談**和**ゲーム実況**。**歌词不翻译**（唱歌场景不在本版目标内）。

## 一、启动

1. 解压到任意目录（路径尽量别带中文），双击 `LiveSub-0.3.0\LiveSub.exe`
2. 第一次会弹「未知发布者」→ 点 **更多信息** → **仍要运行**（程序没有代码签名，不是病毒）
3. 会开一个黑色窗口，**别关**——关掉就是停止字幕

窗口里会打印三行地址，后面都要用：

```
字幕页   http://127.0.0.1:8765/overlay
设置页   http://127.0.0.1:8765/admin
调试页   http://127.0.0.1:8765/overlay?debug=1
```

---

## 二、接进 OBS（第一次配置，约 1 分钟）

1. OBS 里找到 **来源** 面板 → 点 **`+`**
2. 选 **浏览器**
3. 名字随便填（比如 `字幕`）→ 确定
4. 在属性里填：

| 项目 | 填什么 |
|---|---|
| URL | `http://127.0.0.1:8765/overlay` |
| 宽度 | `1920` |
| 高度 | `1080` |

5. 位置拖到画面底部（或在「变换」里把位置设成 `0, 0`）
6. **「不可见时关闭源」不要勾**（勾了会重新加载，字幕会闪）
7. 背景**天生透明**，不需要做任何抠像/色键设置

> 想先看效果不推流：浏览器直接打开 `http://127.0.0.1:8765/overlay?preview=1`

---

## 三、调字体 / 颜色 / 大小 / 背景

浏览器打开 **`http://127.0.0.1:8765/admin`**

左边是 **1920×1080 的实时预览**，右边是设置。改哪个，预览立刻变；点「保存并应用」后，
**OBS 里的字幕也会立刻变**（不用重启程序，也不用刷新 OBS）。

能调的东西：

- **字体**：填系统里已安装的字体名（比如 `思源黑体`），可写多个用逗号分隔
- **字号**：中文、日文分开调
- **颜色**：中文字色、日文字色
- **描边**：开关 + 颜色 + 粗细（不想要描边就把开关关掉）
- **背景板**：想要黑色半透明长方形——勾上「启用背景」→ 颜色选黑 → 拖透明度
- **位置**：贴底 / 贴顶，距边缘百分比
- **行数**：屏幕上同时显示几行
- **双语**：是否显示日语原文

## 四、加词（模型翻错了就来这里加）

同一个设置页，点 **「词典」** 标签。分两张表：

### 1) 固定表达（整句）

只有**单独说这一句**时才生效。适合寒暄、直播套话：

| 日文 | 中文 |
|---|---|
| こんばんは | 晚上好 |
| おつかれさまでした | 辛苦了 |
| なるほど | 原来如此 |

### 2) 术语（词级）

两种模式，选错了效果会变差：

| 模式 | 做什么 | 适合 |
|---|---|---|
| `pre` | 译前把日文词换成中文，再送模型 | 片假名专名、游戏名、食物名（模型会原样保留注入的中文） |
| `post` | 正常翻译，译后把「错误写法」换掉 | 句子结构对、只有那个词错（比如 `配信` 被翻成"发送"） |

`post` 的「错误写法」可以写多个，用 `|` 分隔，例如 `发送|发货|传送`。

**加完点「保存词典并热加载」**，立刻生效，不用重启。
下面还有 **试译** 框：输入一句日文，马上能看到用新词典翻出来的结果。

> 词典也会写到程序目录下的 `glossary\`（纯文本、UTF-8、Tab 分隔），想手改也行。
> 想恢复成内置词库，删掉这个目录重启即可。

## 五、不想用界面的话

所有设置都在程序目录的 `config.toml` 里，带中文注释，改完重启 exe 生效。
词典在 `glossary\phrases.tsv` 和 `glossary\terms.tsv`。

## 这个版本新增了什么

- **图形设置页** `/admin`：样式（字体/颜色/描边/背景）实时预览 + 词典增删改热加载
- **术语表 137 条 + 86 条**：高频日常口语（そうなんだ、めんどくさい、しょうがない…）、
  网络用语（草、ワロタ、それな、エモい、てぇてぇ）、直播平台（同接、登録者、コラボ、ギフト）、
  游戏实况（ガチャ、課金、天井、バフ、デバフ、蘇生、リスポーン、RTA）
- **译前补标点**：语音识别输出没有标点，送翻译前补一个句末标点，质量 +0.05，0ms
- **解码护栏 + 译文清洗**：模型偶尔"卡带"，现在检测到循环就收手，最坏延迟 502ms → 180ms

## 翻译质量（诚实版）

| 语料 | 上一版 | 本版 |
|---|---|---|
| 书写体 60 句 | 0.354 | **0.603** |
| 无标点（≈ASR 输出） | 0.273 | **0.504** |
| VTuber 口语 37 句 | 0.180 | **0.259** |

- ✅ 寒暄、高频口语、专有名词、平台用语、游戏术语——可读
- ⚠️ 主播随口的长句、语气、授受关系——大约一半要猜
- ❌ 歌词、方言、多人抢话——不在范围内
