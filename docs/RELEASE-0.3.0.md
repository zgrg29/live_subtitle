# LiveSub 0.3.0

给 OBS 用的本地实时日语→中文字幕。**只采集麦克风，全程离线，不上传音频。**

适用场景：日本 VTuber 风格的**雑談**和**ゲーム実況**。**歌词不翻译**（唱歌场景不在此版本目标内）。

---

## 下载

| 文件 | 说明 |
|---|---|
| `LiveSub-0.3.0-win64.zip` | 绿色版，解压即用。**Windows 10/11 x64**，不用装 Python |

下载后解压到任意目录（路径尽量别带中文和空格），双击 `LiveSub.exe`。
第一次会弹「未知发布者」→「更多信息」→「仍要运行」。

> 包里有 382MB 的模型（识别 153MB + 翻译 229MB），所以压缩包约 600MB。
> 换机器时整个文件夹拷走就能用，不需要联网。

## 第一次使用

1. 双击 `LiveSub.exe`，会开一个黑色控制台窗口，**别关**（关掉就是停字幕）。
2. 浏览器打开 <http://127.0.0.1:8765/overlay?preview=1> 先看样式。
3. OBS → 来源 → `+` → **浏览器** → URL 填 `http://127.0.0.1:8765/overlay`
   → 宽 `1920` 高 `1080` → 位置 `0,0` → **不要**勾「不可见时关闭源」。
4. 字幕背景天生透明，不需要额外设置。

更详细的步骤和踩坑见 [docs/obs-setup.md](docs/obs-setup.md)。

## 这个版本新增了什么

### 术语表（94 条固定表达 + 80 条术语）

翻译完还是不对的词，现在用**零延迟的文本层**补。三块内容：

- **网络用语**：草、ワロタ、それな、わかりみ、エモい、てぇてぇ、ぴえん、エグい、優勝、尊い、卍……
- **直播平台**：同接、登録者、フォロワー、コラボ、ギフト、モデレーター、荒らし、鍵垢、地蔵、民度……
- **游戏实况**：ガチャ、課金、天井、バフ、デバフ、蘇生、リスポーン、ラグ、チート、縛りプレイ、RTA……

自己也能加：编辑程序目录下的 `glossary\terms.tsv`（UTF-8、Tab 分隔），重启生效。
格式和两种模式的取舍写在 README 的「加词 / 改词典」一节。

### 译前补标点

语音识别吐出来的日文是没有标点的，而翻译模型是在带标点的语料上训练的。
现在送翻译前会补一个句末标点，**F1 +0.05，耗时 0ms**。

### 解码护栏 + 译文清洗

模型偶尔会"卡带"（`Flame Flame Flame…`、`帧数 帧数 帧数`）。现在解码时检测到循环就收手，
输出层再折叠一次。最坏情况延迟从 **502ms 降到 180ms**，也不会再往字幕里吐一长串重复。

### 评测工具

```powershell
python tools/eval_mt.py                            # 60 句书写体
python tools/eval_mt.py --strip-punct              # 模拟 ASR 的真实输入形态
python tools/eval_mt.py --set eval/holdout_vtuber.jsonl
```

## 翻译质量（诚实版）

| 语料 | 裸模型 | 本版本 |
|---|---|---|
| 60 句书写体 | 0.354 | **0.603** |
| 60 句无标点（≈ASR 输出） | 0.273 | **0.504** |
| 37 句 VTuber 口语（holdout） | 0.180 | **0.259** |

F1 只用于同一套句子的前后对比，不代表绝对水平。**真实可用性看第三行**：

- ✅ 寒暄、专有名词、平台用语、游戏术语——已经可读；
- ⚠️ 主播随口的长句、语气、授受关系——大约一半要猜；
- ❌ 歌词、方言、多人抢话——不在范围内。

## 已知问题

1. **未签名**，首次运行会弹「未知发布者」，属正常。
2. 包很大（约 600MB），主要是模型；暂时没有瘦身版。
3. 重复双击会因端口占用退出（有提示，但没做单实例锁）。
4. 与 OBS 的联动（场景切换、丢帧看门狗、一键隐藏）还没做，属于 M3。
5. 只支持 Windows x64。

## 需要什么

- Windows 10/11 x64，4 核 CPU 起步（4 核能效核实测可用：短句端到端 p50 0.8–1.2 秒）
- 内存 4GB 以上
- 不需要显卡，不需要联网
