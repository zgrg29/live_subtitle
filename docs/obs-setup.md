# 接进 OBS

目标：在 OBS 里显示一条透明字幕，位置/字号/OBS 场景切换都不折腾。

## 前置

1. LiveSub 已经跑起来（`python -m livesub run`），控制台里有
   `字幕页 http://127.0.0.1:8765/overlay` 这一行；
2. 浏览器打开这个地址能看见字幕（演示模式也有预设台词）。

## 添加浏览器源

1. OBS 左下 **来源** → `+` → **浏览器**
2. 名称随便，比如 `LiveSub`
3. 在属性里填：

| 项 | 值 |
|---|---|
| URL | `http://127.0.0.1:8765/overlay` |
| 宽度 | `1920` |
| 高度 | `1080` |
| 使用自定义帧率 | 不勾 |
| 不可见时关闭源 | **不勾**（勾了会在切场景时重新加载，字幕闪一下 / 短暂空白） |
| 场景变为活动时刷新浏览器 | 不勾 |
| 自定义 CSS | 留空（样式在 LiveSub 的 `config.toml` 里改） |

4. 确定。这个源是透明的，不需要做任何抠像/混合模式设置。
5. 右键源 → **变换** → **适配到屏幕**（或手动设位置 `0,0`）。

## 建议

- **单独放一个场景**，比如 `游戏+字幕`，用 `游戏` 场景复制而来，这样切场景不会丢字幕源；
- 把字幕源放在**最上层**，避免被摄像头/贴图挡住；
- 如果 OBS 画布不是 1080p，字幕会自动按宽度等比缩放，不用改配置；
- 想快速对比效果：把 URL 临时改成 `.../overlay?preview=1`，它会显示三条固定示例，不依赖识别结果。

## 检查是否真的连通

浏览器开 `http://127.0.0.1:8765/overlay?debug=1`：

- 左上角出现黑色小面板；
- `已连接` 为绿色；
- 说话时 `延迟` 会刷新数字。

看不到面板 = 没连上，先排查端口和进程。

## 常见问题

**字幕被裁掉一半 / 只显示一行**
浏览器源高度不够，或者你把源缩放了。把源尺寸设回 1920×1080 后重新"适配到屏幕"。

**字幕位置太高/太低**
改 `config.toml`：

```toml
[overlay]
position = "bottom"
margin_percent = 8    # 距底边 8%
```

**字太小/太大**
改 `overlay.zh_size`（按 1920 宽计算）。不要用 OBS 缩放源，那样描边会一起变粗。

**一开播字幕就消失**
检查是否勾了"不可见时关闭源"，以及是否切到了没有该源的其他场景。

**麦克风会不会被 OBS 抢走**
不会。LiveSub 以共享模式读取麦克风，OBS 同时使用同一个麦克风没有冲突；
LiveSub 也**不往 OBS 输出任何音频**，不需要在混音器里找它。
