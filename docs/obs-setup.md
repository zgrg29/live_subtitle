# OBS への追加

目標：OBS に透明な字幕を 1 本表示する。位置・文字サイズ・シーン切替で悩まないこと。

## 前提

1. LiveSub が起動している（`python -m livesub run`）。コンソールに
   `字幕ページ ：http://127.0.0.1:8765/overlay` の行が出ている
2. ブラウザでそのアドレスを開くと字幕が見える（デモモードでも台本のテキストが出ます）

## ブラウザソースを追加する

1. OBS 左下の **ソース** → `+` → **ブラウザ**
2. 名前は任意（例：`LiveSub`）
3. プロパティに次を入力：

| 項目 | 値 |
|---|---|
| URL | `http://127.0.0.1:8765/overlay` |
| 幅 | `1920` |
| 高さ | `1080` |
| カスタム FPS を使用 | オフ |
| ソースが非表示のときにシャットダウン | **オフ**（オンにするとシーン切替のたびに再読み込みされ、字幕が一瞬消えます） |
| シーンがアクティブになったときにブラウザを更新 | オフ |
| カスタム CSS | 空欄（スタイルは LiveSub の設定ページ／`config.toml` で変更） |

4. OK。このソースは透明なので、クロマキーやブレンドモードの設定は不要です。
5. ソースを右クリック → **変換** → **画面に合わせる**（または位置を手動で `0,0` に）。

## おすすめ

- **専用のシーンを 1 つ作る**（例：`ゲーム＋字幕`）。`ゲーム` シーンを複製して作ると、
  シーンを切り替えても字幕ソースが消えません
- 字幕ソースは**最前面**に置く（カメラや画像に隠されないように）
- OBS のキャンバスが 1080p でなくても、字幕は幅に合わせて自動で拡大縮小されます。設定変更は不要
- 手早く見た目を確認したいとき：URL を一時的に `.../overlay?preview=1` にすると、
  認識結果に依存せず固定のサンプル 3 行を表示します

## 本当につながっているか確認する

ブラウザで `http://127.0.0.1:8765/overlay?debug=1` を開きます：

- 左上に黒い小さなパネルが出る
- `接続済み` が緑になる
- 話すと `遅延` の数字が更新される

パネルが出ない＝接続できていません。まずポートとプロセスを確認してください。

## よくある質問

**字幕が半分切れる／1 行しか出ない**
ブラウザソースの高さが足りないか、ソースを拡大縮小しています。ソースのサイズを 1920×1080 に戻し、
もう一度「画面に合わせる」を実行してください。

**字幕の位置が高すぎる／低すぎる**
設定ページの「表示位置」と「端からの距離」で調整するか、`config.toml` を変更します：

```toml
[overlay]
position = "bottom"
margin_percent = 8    # 下端から 8%
```

**文字が小さい／大きい**
`overlay.zh_size`（1920 幅基準）を変更してください。OBS 側でソースを拡大縮小すると、
縁取りまで一緒に太くなるのでおすすめしません。

**配信を始めたら字幕が消える**
「ソースが非表示のときにシャットダウン」がオンになっていないか、
そのソースを含まないシーンに切り替わっていないかを確認してください。

**マイクが OBS に取られない？**
取られません。LiveSub はマイクを共有モードで読むため、OBS と同じマイクを同時に使っても競合しません。
また LiveSub は **OBS に音声を出力しません**。ミキサーに表示されないのが正常です。
